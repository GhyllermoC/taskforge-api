# Changelog

Todos los cambios importantes de este proyecto serán documentados en este archivo.

El formato está basado en Keep a Changelog y este proyecto sigue Versionado Semántico (Semantic Versioning).
---

## [1.1.0] - 2026-05-31

### Changed
- Se agregó un parámetro opcional `completed` al endpoint **GET /tasks** para permitir filtrar tareas por estado (pendientes o completadas).
- Mejora menor que amplía la funcionalidad sin alterar la compatibilidad existente.

---

## [1.0.0] - 2026-05-30

### Added

* Creación inicial del proyecto TaskForge API.
* Configuración de FastAPI.
* Implementación del endpoint GET /tasks.
* Implementación del endpoint POST /tasks.
* Implementación del endpoint PUT /tasks/{id}.
* Implementación del endpoint DELETE /tasks/{id}.
* Integración de documentación automática mediante Swagger UI.
* Generación automática de especificación OpenAPI.
* Creación del archivo README.md.
* Configuración inicial del repositorio Git.
